# RightMemory Demo Script

Show a fresh agent continuing familiar work with less repeated explanation, then show where the useful learning comes from.

## Setup

Use disposable memory and skill directories:

```bash
./install.sh --mode cli-agent /tmp/rightmemory-demo /tmp/rightmemory-demo-skills
```

Enable the installed daily entry and configure the internal executor. Seed a small Memory graph with a real project's durable context and a human-owned Pursuit direction. Keep the example small enough that viewers can understand the input and resulting change.

## Recording Beats

1. Start a fresh conversation and ask the agent to continue a familiar task. Show retrieval of relevant ordinary context, guidance, and work experience.
2. Let the user supply a meaningful correction or a missing judgment while the agent completes the work. Show the actual resulting artifact, not only a claim of success.
3. At a natural boundary, show the useful evidence entering the shared `rightmemory submit` path once. The submitting agent preserves evidence without manufacturing a final rule or skill.
4. Show the raw candidate available to relevant retrieval before curation.
5. Let the configured worker process Memory, guidance, and skills. Show each domain's change or no-change judgment, completion receipts, and automatic removal of the fully processed raw candidate. Useful retained cases or experiences remain visible.
6. Start another fresh conversation with a short request and a changed input. Show the relevant skill or experience being retrieved and used. Any remaining user intervention is part of the result, not something to hide.
7. Finish with the inspectable files and Git diff. The Pursuit map is unchanged by ordinary learning; the user can still edit it through its own workflow.

## Narration

> RightMemory carries useful context, guidance, and work experience across conversations. One daily entry captures and retrieves evidence. Three curators share their own core between updates and requested maintenance. An interaction can be useful before it becomes a stable rule or a reusable skill. The aim is for later agents to do meaningful work with less repeated direction, while keeping the evidence and the result inspectable.

A successful first run demonstrates that case. The second run is where the demo begins to show transfer; do not claim broad reliability from a single example.
