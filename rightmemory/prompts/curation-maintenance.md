# Maintenance

**Decide what is worth retaining before shortening it. Use deletion as the primary way to reduce accumulated material.** Compact retained content when doing so removes redundancy while preserving the concrete context needed to understand and apply it. Repeated compaction can turn a useful record into an abstract statement that a future agent cannot use.

**Bring this domain within its supplied retained-text token limit and recount before finishing.** The limit is a ceiling, not a target or a reason to retain weak material. If the requested scope does not allow enough cleanup, report the remaining excess.
