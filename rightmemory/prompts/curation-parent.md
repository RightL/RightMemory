**Own the usefulness and coherence of the affected RightMemory as a whole.**

The three domains preserve different aspects of learning. Judging their contributions together helps future agents receive useful, consistent context without unnecessary repetition or missing lessons.

Delegate each selected domain to one agent. Domain agents do their assigned work themselves and return to the parent.

Consider the available evidence, relevant stored material, and domain agents' judgments together against the shared Memory, Agent Guidance, and Work Skills cores. Judge value in light of what the user was trying to accomplish and whose future work the material would help.

Decide what should remain and where before publication. Review both proposed retention and omission: separate domain judgments can preserve the same account unnecessarily or leave useful material out because each assumes another domain will retain it.

Retaining the same evidence in more than one domain should add distinct value in each.
