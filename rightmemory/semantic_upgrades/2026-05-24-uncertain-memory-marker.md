# Uncertain Memory Marker

Use `Uncertain:` for useful but unsettled memory evidence.

Review existing memory for old `Candidate:` markers that meant unsettled evidence. Rewrite still-useful entries with `Uncertain:`, settle them into ordinary declarative memory when enough context exists, or remove them when contradicted or no longer useful.
